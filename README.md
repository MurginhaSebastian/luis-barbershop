# Luis Barbershop

Web app para una barbería: reserva de citas, agenda de barberos y venta cruzada de productos.

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · shadcn/ui · Zod, organizada en Clean
Architecture (`src/core`, `src/application`, `src/infrastructure`, `src/presentation`, `src/app`).

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```
